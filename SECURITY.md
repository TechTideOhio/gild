# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in gild, please do not file a public issue.
Report it responsibly via private email to `security@techtide.ai` or via GitHub Security Advisories.

Reports receive an initial response within 24 hours and a remediation path within 72 hours.
